# 🥔 SOL-ValPotato

SOL-ValPotato 是一款基于 [Spice of Life: Valheim Edition](https://www.curseforge.com/minecraft/mc-mods/spice-of-life-valheim-edition) 的 Minecraft 生存模组，完全重写了原有的代码，保留了核心机制，并增强了与其他模组的兼容性，特别是与 [Some Assembly Required](https://www.curseforge.com/minecraft/mc-mods/some-assembly-required) 的集成。

## 🧭 模组简介

在原版 Minecraft 中，饥饿系统往往被视为一种烦人的机制，玩家只需不断进食即可维持冲刺能力，缺乏策略性和挑战性。

SOL-ValPotato 通过引入类似《Valheim》的三槽食物系统，赋予食物更多的战略意义：

* 每次进食会填充一个食物槽，提供特定的生命值和再生效果。
* 食物效果持续一段时间，期间无法重复食用相同的食物。
* 鼓励玩家多样化饮食，合理搭配不同食物以获得最佳效果。

这种机制不仅增加了游戏的生存挑战，也提升了食物系统的深度和趣味性。
